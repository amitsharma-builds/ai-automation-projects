# AI Business Intelligence Bot

## What it does
Upload any CSV dataset → Get instant AI-powered 
business analysis with charts, executive report, 
and Q&A with Claude.

## Features
- Auto-detects data types and generates relevant charts
- Claude AI writes a full executive report
- Ask any question about your data in plain English
- Download report and charts

## How to run
pip install -r requirements.txt
streamlit run app.py
